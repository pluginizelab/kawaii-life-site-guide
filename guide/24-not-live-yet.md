# 24. Not live yet

These parts of the agreed project are still being finished. Until they're done, the site behaves as described here:

| Feature | Today |
| --- | --- |
| **bKash, Nagad and SSLCommerz payments** | Only Cash on Delivery and Bank Transfer are on (**WooCommerce → Settings → Payments**). |
| **Pathao courier** | Not connected. Book Pathao deliveries with the courier directly. Steadfast is connected (section 10.3). |
| **COD verification and payment SMS** | Not built yet. Order status SMS, login codes and abandoned-cart texts work, and promotional campaigns are sent from Alpha SMS with the **SMS Contacts** export (section 20.1). |
| **"Just for You" on the home page** | The block exists; it will be added to the home page. |
| **WhatsApp chat button** | Needs the shop's number. (The footer's social links appear once you add your profiles in Theme Options, section 2.5.) |
| **Google and Facebook login buttons** | They're shown on the login card but don't work yet. |
| **Blocking fraudulent customers** | Not available yet. |
